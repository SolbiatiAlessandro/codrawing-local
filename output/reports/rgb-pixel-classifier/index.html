CoDrawing · RGB classifier experiment

One classifier, with color built in

The clean candidate is an official MobileNetV3-small backbone fine-tuned on native RGB pixel canvases. Shape and color enter the same network and produce one 10-class probability vector—no text prompts and no separate palette bonus.

Recommendation

Use MobileNetV3-small as the production architecture, then fine-tune it on our actual colored pixel-canvas distribution.

MobileNetV3-small is an official, mobile-oriented image-classification architecture available directly from TorchVision [S1]. The target-specific final layer is ours; there is no trustworthy off-the-shelf checkpoint with CoDrawing's classes and visual style.

What is—and is not—ready

Architecture: yes

MobileNetV3-small is the strongest clean candidate: conventional RGB classification, one output head, modest file size, and straightforward export to ONNX or TFLite. The official architecture was designed for low-resource use [S2].

Download the experimental checkpoint [M1].

Training corpus: not yet

The experiment temporarily used recolored sketch bitmaps plus procedurally varied canvas outlines to isolate the architecture and color behavior. Because we do not want Quick Draw as the product data source, this checkpoint should not be merged as the game model.

Required next step: retrain the same model on saved CoDrawing canvases and independently authored 24×24 target examples, with canonical, alternate, grayscale, incomplete, and dark-background variants. Keep an untouched human-drawn test set.

Available colored datasets

No credible ready-made small classifier surfaced with both CoDrawing's object vocabulary and colored pixel-art training. Two datasets can help with domain pretraining, but neither replaces target-specific examples:

PixelGPT 24×24

20,000 native 24×24 sprites, at most five colors, 133 categories, CC BY 4.0. It is well matched to resolution and palette, but its categories do not cover our target set cleanly [S3].

Icon645

645,687 colored icons over 377 classes; useful evidence that icon-domain pretraining beats natural-image features. Its released research assets are larger, and the reported dataset license is CC BY-NC-SA, so it needs a usage review [S4].
